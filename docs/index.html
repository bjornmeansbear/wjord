Why it exists

I write in Markdown and set books in InDesign. For years the trip went Markdown to HTML to XML to InDesign, by hand, one conversion at a time. It worked once. It never worked twice.

Pandoc already turns Markdown into ICML, the InCopy story format that InDesign places as a linked file. Wjord is the glue around it: a watcher, clean style names, your own styles from plain classes, and a specimen for building the template.

Four steps

  1. Build a template, once

    Run wjord specimen and place the file in a new document. Every style appears in your panels. Design them, delete the story, save as .indt.

  2. Write

    One Markdown file per chapter, in one folder. Mark a block ::: pullquote to make your own style.

  3. Watch

    Run wjord watch in that folder and leave Terminal open. Each save rebuilds that chapter's .icml.

  4. Place and update

    File → Place the .icml. After an edit, the Links panel flags the story. Update it and the text reflows.

The one rule

Never format the text in InDesign.

An update replaces the whole story. Any local change goes with it. Every decision belongs in a paragraph or character style, where it applies everywhere at once.
